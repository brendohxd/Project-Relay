# Project Relay assets

Single design pack for brand, icons, and badges.

## Layout

```text
Assets/
  README.md                 ← this file
  project-relay-assets/     ← full visual pack (source of truth for design exports)
apps/console/assets/        ← same pack copied into the multipage console
docs/assets/                ← generated by `npm run pages:build` for GitHub Pages
```

## Rules

1. **Design / export work** goes in `Assets/project-relay-assets/`.
2. **Site runtime** uses `apps/console/assets/` (HTML `src` paths point here).
3. After updating the pack, sync into the console and rebuild Pages:

```bash
# From repo root (PowerShell example)
robocopy Assets\project-relay-assets apps\console\assets /E
copy /Y apps\console\assets\logo\logo-icon.svg apps\console\favicon.svg
npm run pages:build
npm run pages:check
```

4. Do **not** nest a second `project-relay-assets` folder inside the pack.
5. Prefer **SVG** on the site; PNG is for README, social, or non-SVG hosts.
